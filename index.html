先把丑话说在前面

会不会封号？
不修改客户端、不做注入或逆向；但界面自动化仍可能违反微信用户协议、带来账号限制，风险自担。项目内置了风险横幅、写闸门、间隔抖动、失败不重发、看门狗自动暂停等护栏；建议只用自己的号、低频、不群发、不代挂，最好先拿小号试。
支持 macOS / Linux / Docker 吗？
不支持，只支持 Windows 10 / 11。发送依赖桌面里微信 PC 版窗口的 OCR 定位 + 坐标点击，服务器上没有可操作的窗口。
数据存在哪？会上传吗？
全部在工程目录 data\（SQLite + 日志 + 截图），只在本机。聊天上下文是否发云端由每个模型档位的 allow_context 决定，默认云端档位不带上下文。
Web 面板安全吗？
面板只监听本机 127.0.0.1，且必须用启动时打印的、带 #token= 的完整地址打开。把带 token 的链接发出去 = 别人能用你的机器人发消息，别外传。
